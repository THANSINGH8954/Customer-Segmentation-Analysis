# 🧩 Customer Segmentation Analysis

Group customers into statistically distinct, business-actionable segments based
on demographics and purchasing behavior (RFM: recency, frequency, monetary
value), then turn each segment into a targeted marketing recommendation.

## 🧭 Project overview

**Task:** develop a customer segmentation model using data analytics
techniques to group customers by purchasing behavior, demographics, and
spending patterns, and turn the segments into actionable marketing
recommendations.

**Requirements covered:**
- ✅ Data Cleaning
- ✅ Customer Segmentation (K-Means clustering)
- ✅ Data Visualization
- ✅ Statistical Analysis
- ✅ Business Recommendations

> **About the data:** this repo ships with a synthetic customer dataset
> ([`data/customer_data_raw.csv`](data/customer_data_raw.csv), ~1,200 rows)
> generated by [`scripts/generate_data.py`](scripts/generate_data.py), built
> from 5 underlying customer archetypes so the clustering has real,
> recoverable structure — with realistic messiness layered on top
> (duplicates, missing values, implausible ages, income sign errors) so the
> cleaning step has genuine work to do. **Drop in your own customer export
> with the same column names to segment real data.**

## 📊 The 5 segments found

| Segment | % of Customers | Avg Spend | Avg Frequency | Avg Recency (days) | Marketing Focus |
|---|---|---|---|---|---|
| **High-Value Loyalists** | 18.3% | $4,120 | 27.1 | 9 | Retention, loyalty perks, premium upsell |
| **Occasional Big Spenders** | 15.0% | $2,183 | 5.1 | 60 | High-AOV bundles timed to their cycle |
| **Young Digital Shoppers** | 24.6% | $806 | 16.4 | 18 | Mobile/social, frequent low-AOV promos |
| **Budget Shoppers** | 21.3% | $653 | 13.9 | 25 | Value messaging, bundles, loyalty points |
| **New / Low-Engagement** | 20.8% | $121 | 1.9 | 80 | Onboarding incentives, churn prevention |

Clustering used **K-Means (K=5)** on standardized age, income, tenure, and RFM
features, with **PCA** for 2D visualization. Full methodology, the elbow/
silhouette analysis behind the K=5 choice, and all supporting charts are in
the [notebook](notebooks/customer_segmentation.ipynb).

## 🖥️ The interactive dashboard

The dashboard (`dashboard/app.py`) is built with **Streamlit** + **Plotly**
and lets you filter by segment, membership tier, channel, and age while
exploring:

- **Segment Overview** — customer counts, share by segment, PCA scatter
- **Segment Profiles** — average metrics per segment (heat-styled table), metric comparison, segment × membership-tier heatmap
- **Explore** — free-form scatter/box plots across any two RFM/demographic metrics, colored by segment
- **Raw Data** — a filterable, downloadable view of the segmented dataset

It reads directly from `outputs/customers_with_segments.csv`, so it always
reflects whatever the notebook (or `scripts/run_analysis.py`) most recently
produced.

## 🚀 Getting started

### 1. Clone and install dependencies

```bash
git clone https://github.com/<your-username>/customer-segmentation-analysis.git
cd customer-segmentation-analysis

python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate

pip install -r requirements.txt
```

Requires **Python 3.10+**.

### 2. (Optional) Regenerate the sample dataset

```bash
python scripts/generate_data.py
```

### 3. Run the analysis pipeline

Cleans the data, runs EDA/statistical analysis, fits K-Means, profiles
segments, and writes everything the dashboard needs into `outputs/`:

```bash
python scripts/run_analysis.py
```

Or, for the full narrative walkthrough with explanations, open the notebook:

```bash
jupyter notebook notebooks/customer_segmentation.ipynb
```
*(Run All Cells — the notebook writes the same files as `run_analysis.py`.)*

### 4. Launch the interactive dashboard

```bash
streamlit run dashboard/app.py
```

Then open the URL Streamlit prints (usually `http://localhost:8501`).

## 🔎 Using your own data

Replace `data/customer_data_raw.csv` with your own export using these
columns (rename/map your columns to match):

| Column | Type | Description |
|---|---|---|
| `CustomerID` | string | Unique customer identifier |
| `Age` | int | Customer age |
| `Gender` | string | Customer gender |
| `City` | string | Customer location |
| `AnnualIncome` | float | Estimated/reported annual income |
| `MembershipTier` | string | Loyalty tier (Basic/Silver/Gold/Platinum) |
| `PreferredChannel` | string | Online / In-Store / Mobile App |
| `TenureMonths` | int | Months since first purchase |
| `RecencyDays` | int | Days since most recent purchase |
| `Frequency` | int | Number of purchases in the analysis period |
| `MonetaryTotal` | float | Total amount spent in the analysis period |
| `AvgBasketValue` | float | Average order value |

Then re-run steps 3–4 above. If your data has more or fewer behavioral
features, adjust the `cluster_features` list in `scripts/run_analysis.py`
(and the matching cell in the notebook) accordingly.

## 🛠️ Methodology summary

**Data Cleaning**
- Standardized text fields (trimmed whitespace, consistent casing)
- Removed duplicate customer rows
- Flagged and imputed implausible ages (e.g. age = 2 or 145) and fixed
  income sign errors rather than deleting the affected rows
- Imputed remaining missing values (median for numeric, mode for categorical)

**Statistical Analysis & Visualization**
- Descriptive statistics and distribution plots for all numeric features
- Correlation analysis between demographics and RFM behavior
- Income-by-membership-tier and frequency-vs-spend relationships

**Customer Segmentation**
- Features standardized with `StandardScaler` (required for distance-based
  clustering since age/income/spend live on very different scales)
- K selected by comparing the elbow method and silhouette score across
  K=2–10, balancing statistical separation against business interpretability
- Final model: **K-Means, K=5**, visualized in 2D via **PCA**

**Business Recommendations**
- Each segment profiled on age, income, tenure, recency, frequency, spend,
  and basket size, then mapped to a specific marketing action (retention,
  win-back, onboarding, value messaging, etc.) — see
  [`outputs/insights.json`](outputs/insights.json) and the notebook's final
  section for full detail.
